# Philosophers of Autonomy

This corpus builds a focused knowledge base of philosophers and theorists whose work illuminates autonomy, self-governance, freedom, agency, authority, and the conditions that make collective self-rule possible.

It uses **Compiled Knowledge Infrastructure**:

```text
raw sources
-> agent-maintained wiki
-> schema and workflow conventions
```

Raw materials remain inspectable and stable. The wiki is the compiled layer where agents maintain thinker pages, concept pages, tension pages, cross-references, and Stack mappings.

## Directory Structure

- `raw/` — source records, bibliographic notes, excerpts where legally appropriate, and links to source material.
- `wiki/thinkers/` — compiled pages for individual thinkers.
- `wiki/concepts/` — compiled pages for autonomy-related concepts.
- `wiki/tensions/` — compiled pages for recurring philosophical tensions.
- `schema.md` — rules for ingesting and maintaining the corpus.
- `index.yaml` — agent-readable routing index.

## Governance Rule

Every compiled page must separate:

1. **Source claim** — what the source or source record supports.
2. **Interpretive synthesis** — the corpus-level reading or relation between sources.
3. **Stack application** — how the material may illuminate the Autonomy Stack.

Agents should not convert interpretation into apparent source fact.
