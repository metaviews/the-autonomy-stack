# Stack Indexes

These lightweight indexes give agents stable entry points into the Autonomy Stack without replacing the prose documents. They are intentionally small and descriptive. They are not formal schemas, validation standards, or complete summaries.

## Files

- [layers.yaml](layers.yaml) lists the six Stack layers, their core questions, and primary documents.
- [patterns.yaml](patterns.yaml) lists the 20 pattern files with primary layer engagements.
- [provocations.yaml](provocations.yaml) lists the eight provocations and their current governance concern.

Agents should use these indexes for orientation and routing, then read the linked source documents before making claims or applying a tool.
