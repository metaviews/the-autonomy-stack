# Compiled Knowledge Usage Protocol

This protocol tells agents how to use compiled knowledge corpora without turning synthesis into false authority.

## Use Order

1. Start with the corpus index to identify relevant thinkers, concepts, tensions, and source records.
2. Read compiled wiki pages for orientation, cross-references, and Stack applications.
3. Read raw source records before making source claims.
4. Mark whether each claim is a source claim, interpretive synthesis, or Stack application.
5. If evidence is thin, name the uncertainty rather than filling the gap.

## Claim Types

**Source claim:** A statement grounded in a listed source record.

**Interpretive synthesis:** A connection or abstraction made by the corpus maintainer or agent.

**Stack application:** A translation from source or synthesis into Autonomy Stack layers, patterns, tools, or governance questions.

## Agent Requirements

- Do not cite a wiki page as if it were a primary source.
- Do not collapse disagreement among thinkers into a single doctrine.
- Preserve marginal and persecuted traditions when routing through the corpus.
- Prefer cross-references over invented analogies.
- Surface tensions when a concept can support more than one governance design.

## Failure Modes

- Treating synthesis as source fact.
- Optimizing for canonical thinkers while dropping anti-authoritarian, abolitionist, Indigenous, feminist, or stateless governance traditions.
- Using concepts as labels without reading the associated tensions.
- Applying a governance concept without identifying which Stack layer it affects.
