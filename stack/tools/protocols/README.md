# Agent-Operable Protocols

These prompts convert the Agentic Governance Toolkit into stepwise agent instructions. Use them when an agent needs to apply a governance tool during planning, review, deployment, or documentation work.

## Protocols

- [Apply Agent Authority Card](apply-agent-authority-card.md)
- [Apply Delegability Review](apply-delegability-review.md)
- [Apply Reversibility Map](apply-reversibility-map.md)
- [Apply Contestability Protocol](apply-contestability-protocol.md)
- [Apply Reasoning Trace Standard](apply-reasoning-trace-standard.md)
- [Apply Human-in-the-Loop Adequacy Test](apply-human-in-the-loop-adequacy-test.md)
- [Apply Agent Ecosystem Audit](apply-agent-ecosystem-audit.md)
- [Apply Stewardship Accountability Register](apply-stewardship-accountability-register.md)
- [Apply Authority Migration Check](apply-authority-migration-check.md)

## General Rule

Do not treat a completed protocol as approval to act. A protocol output is a governance diagnosis. If the output identifies missing authority, unknown reversibility, absent contestability, or formal-only human review, stop and request human judgment.
