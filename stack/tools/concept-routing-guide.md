# Concept Routing Guide

This guide helps agents decide when the philosopher autonomy corpus should inform an agentic governance tool. It does not replace source review. Use it with the [Compiled Knowledge Usage Protocol](../indexes/compiled-knowledge-usage.md).

## Routing Rule

When a governance tool touches autonomy, authority, care, commons, legibility, refusal, abolition, education, or shared infrastructure, consult the relevant corpus pages before finalizing the tool output.

Name the claim type when importing corpus material:

- **Source claim:** grounded in a raw source record.
- **Interpretive synthesis:** derived from a wiki concept, tension, or thinker page.
- **Stack application:** translated into a governance requirement, risk, or design question.
